# Glossary

The words this office uses. Employees use the **Say** column in anything people read, never the code name.

| Say | Means | Don't say (old or code names) |
|---|---|---|
| task | one request moving through inbox → out → done | job, ticket |
| employee | a subagent in `.claude/agents/` | bot, agent |
| gate | a step that waits for the user's yes | checkpoint |
